# 愷愷的寫字冒險

給五歲小朋友在 iPad 上玩的闖關學習遊戲。

- **數字島**：0～9 筆順練習，另有「6 8 特訓」
- **注音森林**：37 個注音符號的筆順練習，有示範動畫、描寫和自己寫
- **地球島**：認識世界各國的國旗、位置和首都（中英文）

## 檔案

| 檔案 | 說明 |
|---|---|
| `index.html` | 遊戲本體 |
| `world.json` | 世界地圖資料 |
| `snd/F*.mp3`、`snd/M*.mp3` | 注音讀音（女聲、男聲） |
| `snd/c*.mp3` | 例字和數字的國字讀音 |

## 資料來源

- 注音筆順、注音讀音、國字讀音：教育部《國字標準字體筆順學習網》 https://stroke-order.learningweb.moe.edu.tw/
- 世界地圖：Natural Earth（公有領域） https://www.naturalearthdata.com/
- 數字筆順、英文與國名語音：自行製作／裝置內建語音
